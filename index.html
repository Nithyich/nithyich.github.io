01
Moody's Analytics Enterprise API Integration — Full Product Suite
REST APIKYC / AMLFintech

At Moody's Analytics I lead end-to-end API integration of the full product suite — Entity Verification API (EVA), MaxSight, Sanctions 360, Orbis, and KYC API — into enterprise client systems across banking, insurance, and compliance-heavy industries. Every integration involves navigating complex regulatory requirements, varied client tech stacks, and tight go-live timelines.

Problem

Enterprise clients struggled to integrate Moody's APIs independently — authentication failures, schema mismatches, missing use cases, and no standardised onboarding process meant lengthy delays and repeated back-and-forth.

What I did

Built a Postman library of 50+ use cases covering all products. Redesigned intake and verification workflows end-to-end. Advised clients on OAuth 2.0, rate limiting, retry logic, and error handling. Performed structured root cause analysis on failing endpoints across auth, schema, and network layers.

Outcome

Onboarding time cut from 3 weeks to 5 days. P1 incidents resolved within 48 hours. Postman library adopted as team standard. 3 API enhancement requests fed back into the product roadmap from recurring client pain points.

↓ 76% reduction in onboarding time · 48hr P1 resolution

Process DesignPower BIMainframe

Problem

What I did

Outcome

~40% reduction in manual reporting effort. Real-time executive visibility for CFOs across CEEMEA and AP. Zero critical defects across 3 platform releases. IBM Q2 CIO Hero award.

AT&T Global Network Services Incident Triage Automation
AutomationITILInfrastructure

AT&T's EMEA network support team handled hundreds of incidents per week across enterprise clients. Analysts manually categorised and routed every ticket — a repetitive process that delayed first-response time and consumed analyst bandwidth.

Problem

What I did

Analysed 6 months of incident data to identify recurring categories. Proposed and documented scripted CRM routing rules. Worked with tooling team to implement automated categorisation workflows.

Outcome
